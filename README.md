## Лабораторна робота №6
# REST Chat Client

## Запуск сервера

1. Перейти в папку `server.rest`
2. Виконати:

```
mvn clean package exec:java "-Dexec.args=localhost 8080"
```

Або:

```
start.cmd
```

## Запуск клієнта

Запустити `Main.java` в IntelliJ IDEA.

Для тестування можна запускати кілька клієнтів одночасно.

## Доступні команди

```
ping
echo <text>
login <username> <password>
list
msg <username> <message>
file <username> <path>
drain
exit
```

## Опис роботи

* `ping` — перевірка з’єднання з сервером
* `echo` — відправка тексту і отримання його назад
* `login` — реєстрація або вхід користувача
* `list` — список користувачів
* `msg` — відправка повідомлення іншому користувачу
* `file` — відправка файлу
* `drain` — примусове отримання та видалення повідомлень/файлів
* `exit` — вихід з програми

## Особливості

Іноді сервер повертає статус `406 (Too many pending messages)` навіть для нових користувачів.

Це пов’язано з внутрішнім станом серверної реалізації.

Клієнт коректно:

* відправляє HTTP-запит
* обробляє відповідь сервера
* виводить повідомлення про помилку
